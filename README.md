# html-effectiveness

An AI skill that produces rich, interactive, self-contained HTML artifacts instead of Markdown — covering explorations, code reviews, design systems, prototypes, research reports, slide decks, and custom editing interfaces.

## Acknowledgments

This project draws inspiration and reference materials from the following open-source work:

- **[html-effectiveness](https://github.com/ThariqS/html-effectiveness)** by [Thariq Shihipar](https://x.com/trq212) — The original article and 20 HTML demo examples demonstrating the "unreasonable effectiveness of HTML" as an output format for AI agents. ([Live examples](https://thariqs.github.io/html-effectiveness/))
- **[Kami (紙)](https://github.com/anthropics/kami)** by [Tw93](https://github.com/Tw93) — A document typesetting skill with a polished design system. Studied for skill architecture patterns and template structure.
- **[AntV Infographic](https://github.com/antvis/infographic)** by [AntV](https://github.com/antvis) — A declarative infographic visualization engine. Referenced for infographic generation patterns and visual design language. (MIT License)
